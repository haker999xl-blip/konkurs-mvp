# Fallback-видео: инструкция оператору

Видео записываете вы, сэр: у меня нет доступа к записи экрана. Ниже — точный порядок, чтобы получилось с первого дубля и без монтажа.

## Что должно быть на экране

Две вкладки браузера, обе на `http://localhost:5173` (или на адресе `npm run preview`):

| Вкладка | Кто | Что показывает |
| --- | --- | --- |
| 1 | Учитель | Админ-панель, очередь заявок |
| 2 | Ученик | Кабинет Марии Соколовой |

Вкладки расположите рядом (окно браузера на весь экран, 1280×800 и шире). Вкладку ученика держите видимой во время подтверждения — именно там видно анимацию.

## Подготовка за 3 минуты

1. `npm run build` затем `npm run preview` — так быстрее и стабильнее, чем dev.
2. Откройте первую вкладку: `/login` → «Анна Николаевна» → «Войти».
3. Кнопка «Сбросить демо» → «Сбросить» (вернёт исходные 12 заявок и счёт 243).
4. Вторая вкладка: `/login` → «Мария Соколова» → «Войти» (она же основной демо-аккаунт).
5. Первая вкладка: `/admin`. В очереди должны быть 4 заявки.
6. Закройте лишние вкладки и уведомления, включите «Не беспокоить».
7. Запись: Win + Alt + R (Xbox Game Bar) или OBS, 1080p, 30 fps, курсор виден.

## Что проверить на записи

- Звук: голос слышно, шумов нет (или видео без звука — тогда субтитры не нужны, но текст в презентации дублирует).
- В кадре нет личных файлов, папок, чатов — только браузер.
- В момент подтверждения обе вкладки видны одновременно (или переключение занимает не больше секунды).
- Числа на экране: было 243 балла / 62% / 3 из 4 → стало 338 / 87% / 4 из 4. Если числа другие — значит демо не сброшено, перезапишите.

## Если что-то пошло не так

| Проблема | Решение |
| --- | --- |
| Вкладка ученика не обновилась | Проверьте, что обе вкладки на одном адресе и порт один; перезагрузите вкладку ученика |
| Очередь пуста | «Сбросить демо», затем повторите |
| Скачивание диплома открылось в новой вкладке | Это нормально, вернитесь назад |
| Запись смазана | Пишите 1080p при 30 fps, окно браузера не двигайте |
