# Fallback-видео: инструкция оператору

Видео записываете вы, сэр: у меня нет доступа к записи экрана. Ниже — точный порядок, чтобы получилось с первого дубля и без монтажа.

## Что должно быть на экране

Две вкладки браузера, обе на одном адресе (`npm run preview` → `http://localhost:4173`):

| Вкладка | Кто | Что показывает |
| --- | --- | --- |
| 1 | Организатор | Админ-панель, очередь достижений |
| 2 | Ученик | Кабинет Марии Соколовой |

Вкладки расположите рядом (окно браузера на весь экран, 1280×800 и шире). Вкладку ученика держите видимой во время подтверждения — именно там видна анимация.

## Подготовка за 3 минуты

1. `npm run build`, затем `npm run preview` — так быстрее и стабильнее, чем dev.
2. Первая вкладка: `/login` → вкладка «Быстрый вход» → «Мария Соколова» → «Войти». Добавьте достижение: категория «Олимпиада», название «Призёр городской олимпиады по информатике», баллы 70 → «Отправить на проверку».
3. Вторая вкладка: `/login` → «Анна Николаевна» → «Войти» → `/admin`. Кнопка «Сбросить демо» → «Сбросить», затем повторите шаг 2 (сброс стирает только что добавленное).
4. В первой вкладке обновите страницу (F5) — она снова под ученицей. В очереди на проверке 5 достижений.
5. Закройте лишние вкладки и уведомления, включите «Не беспокоить».
6. Запись: Win + Alt + R (Xbox Game Bar) или OBS, 1080p, 30 fps, курсор виден.

## Что проверить на записи

- Звук: голос слышно, шумов нет (или видео без звука — тогда текст в презентации дублирует).
- В кадре нет личных файлов, папок, чатов — только браузер.
- В момент подтверждения обе вкладки видны одновременно (или переключение занимает не больше секунды).
- Числа на экране: было 243 балла → стало 308 (243 + 65). Если цифры другие — демо не сброшено, перезапишите.

## Если что-то пошло не так

| Проблема | Решение |
| --- | --- |
| Вкладка ученика не обновилась | Обе вкладки должны быть на одном адресе и порту; обновите вкладку ученика (F5) |
| В очереди нет нового достижения | Проверьте, что отправляли под учеником, а не организатором; «Сбросить демо» и повторите |
| Очередь пуста | «Сбросить демо», затем повторите подготовку |
| Запись смазана | Пишите 1080p при 30 fps, окно браузера не двигайте |
| Не поднимается сервер | `npm run preview` заново, база `data/hackathon.db` сохранится |
