# Демо-сценарий: 2 минуты 30 секунд

## Подготовка (до показа, 10 минут)

- [ ] `npm run build` прошёл, `npm run preview` открыт на `http://localhost:4173`.
- [ ] Масштаб страницы в браузере 100%, окно развёрнуто на весь экран.
- [ ] Две вкладки: первая — ученик, вторая — организатор (вкладки не зависят друг от друга).
- [ ] База сброшена: админ-панель → «Сбросить демо». После сброса 7 аккаунтов, 12 достижений, 4 конкурса.
- [ ] Темы и уведомления ОС выключены, браузер в режиме без панели закладок.
- [ ] В `data/hackathon.db` есть демо-данные; импорт и отчёт проверены заранее.
- [ ] Проверить, что вход по паролю работает (`demo1234`) — если жюри попросит.

Если что-то падает — смотрите [fallback-video.md](fallback-video.md): там запись экрана и план «Б».

## Смотреть на репетициях

- Не открывать третью вкладку — две уже дают эффект «живой» синхронизации.
- После подтверждения переключаться на первую вкладку **вручную**, а не ждать — так видна анимация.
- Не прокручивать кабинет во время доклада: цифры и список достижений должны быть в кадре.

## Что ответить на вопросы жюри

| Вопрос | Ответ |
| --- | --- |
| «Где хранятся данные?» | SQLite на сервере (`node:sqlite`), файл `data/hackathon.db`. Не localStorage. |
| «Пароль как храните?» | `scrypt` с солью, в базе только `scrypt$соль$хеш`; проверка через `timingSafeEqual`. |
| «Как защищаете от подмены баллов?» | Всё валидируется на сервере: 0–500, только целое, дата не в будущем, категория из списка. Ученик всегда создаёт `pending`. |
| «Почему диплом SVG, а не PDF?» | Осознанно: без внешних библиотек, масштабируется, можно распечатать; PDF — следующий шаг. |
| «Что с однофамильцами?» | Аккаунт уникален парой «имя + класс» (`login_key`), однофамильцы не конфликтуют. |
| «Как это масштабируется?» | Слой `api.ts` и `useStore()` уже отделены от страниц: замена на REST-сервис или облако — без переделки интерфейса. |
| «Какие нестандартные данные проверяли?» | Пустые поля, отрицательные и дробные баллы, баллы больше максимума, дата в будущем, неизвестная категория, неизвестный ученик, дубликаты — это `npm run smoke`, 22 проверки. |

## Fallback

1. Если что-то сбоит на защите — переключиться на запись экрана сценария (2:30).
2. Если не подключается сервер — перезапустить `npm run preview`, база сохранится в `data/hackathon.db`.
3. Если база «поехала» — «Сбросить демо» в админ-панели и продолжить со сцены 0:30.
