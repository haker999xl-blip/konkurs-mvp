# Демо-сценарий: 2 минуты 30 секунд

## Подготовка (за 10 минут)

- [ ] `npm run build` проходит, `npm run preview` открыт на `http://localhost:4173`.
- [ ] Окно браузера на весь экран, масштаб 100%, зум страницы 100%.
- [ ] Вкладка 1 — вход, вкладка 2 — та же страница (пока пустая, вход сделаем в кадре).
- [ ] Нажать «Сбросить демо» нельзя без входа, поэтому порядок: войти организатором → «Сбросить демо» → выйти.
- [ ] Проверить, что в очереди есть «Мария Соколова — Кибертурнир "Быстрый ход"» со статусом «Ожидает решения».
- [ ] Обе вкладки открыты заранее: слева ученик, справа организатор — переключение мгновенное.
- [ ] Отключить уведомления ОС, поставить телефон в беззвучный режим.

Если что-то пошло не так — не останавливаться: переключиться на fallback-видео и продолжить рассказ.

## Если спросят про импорт

Админ-панель → «Подставить пример с ошибками» → показать: 2 строки примутся, 5 отклонены с причинами
(дубликат, не хватает полей, отрицательные баллы, неизвестный конкурс). Нажать «Импортировать 2».

Важно: предпросмотр ничего не записывает в базу — цифры в предпросмотре появляются из «сухого» прогона.

## Ответы на неудобные вопросы

| Вопрос | Ответ |
| --- | --- |
| «Это же localStorage, а если сервер?» | Слой данных за интерфейсом `Repository`: меняем реализацию, страницы не трогаем. |
| «Почему не PDF?» | Прототип без внешних зависимостей; SVG печатается и масштабируется, PDF — следующий шаг. |
| «Как проверяли?» | Типы, линтер, production-сборка; ручной прогон всех экранов на 375/768/1280; импорт с ошибочными строками; CSV открывали в Excel; синхронизацию вкладок — с двумя аккаунтами. |
| «Что дальше?» | Бэкенд и авторизация, PDF-дипломы, интеграция с расписанием, уведомления. |

## Fallback

1. Если браузер или сеть подвели — открыть заранее записанное видео (2:30) и комментировать.
2. Если не работает синхронизация вкладок — показать обновление страницы ученика вручную (F5), затем вернуться к рассказу.
3. Если сломались данные — «Сбросить демо» в админ-панели, повтор с шага 1:30.
