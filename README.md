# Конкурс — платформа школьных конкурсов для 7–8 классов

Афиша конкурсов, запись на участие, баллы, рейтинг и дипломы — в одном месте.
Учитель подтверждает участие и выгружает отчёт, ученик видит свой результат и забирает диплом.

Демо-прототип: работает полностью в браузере, без сервера. Данные лежат в `localStorage`,
сессия — в `sessionStorage` (у каждой вкладки своя роль, это нужно для показа «живого» пересчёта).

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:5173
```

Проверка перед защитой:

```bash
npm run build    # tsc -b && vite build
npm run preview  # посмотреть production-сборку
npm run lint     # oxlint
```

Нужен Node.js 20+ (проверено на 24.19.0).

## Сценарий демо (2:30)

1. **0:00–0:25. Афиша.** Вход ученицей. Фильтр по направлению, поиск, карточка конкурса, дедлайн.
2. **0:25–0:50. Запись.** Открыть конкурс «Кибертурнир "Быстрый ход"», нажать «Участвовать» — статус «Ожидает решения».
3. **0:50–1:40. Вау-фича.** Вторая вкладка — вход организатором. Админ-панель: в очереди заявка Марии. «Рассмотреть», поставить 95 из 120, «Подтвердить».
   Переключиться на вкладку ученицы: баллы 243 → 338, прогресс 62% → 87%, место в рейтинге, анимация числа.
4. **1:40–2:05. Рейтинг и диплом.** Рейтинг школы, подиум, своя строка. Кабинет → «Дипломы»: шаблон «Классика»/«Контраст», скачивание SVG.
5. **2:05–2:30. Отчёт.** Админ-панель → «Отчёт для Excel»: CSV с BOM и `;` открывается в Excel без настройки. Импорт участников: «Подставить пример с ошибками» → видно, какие строки и почему отклонены, подтверждение.

Перед показом: админ-панель → «Сбросить демо» (возвращает исходные 4 конкурса и 12 заявок и закрывает сессию во всех вкладках).

## Что умеет

### Ученик
- Афиша: поиск, фильтр по статусу и направлению, сортировка по дедлайну/старту, превью-картинка конкурса.
- Страница конкурса: условия, сроки, число заявок, свой статус и баллы.
- Запись на участие одним нажатием (заявка уходит организатору).
- Кабинет: баллы, место в рейтинге, подтверждённые участия, прогресс, комментарии жюри.
- Диплом: два SVG-шаблона, предпросмотр, скачивание с именем, классом, конкурсом и баллом.
- Рейтинг школы: подиум первых трёх, полная таблица, подсветка своей строки.

### Организатор
- Создание, редактирование и удаление конкурсов с валидацией дат и максимального балла.
- Очередь заявок: выставление баллов в пределах максимума, комментарий, подтверждение или отклонение.
- История решений.
- Импорт участников из CSV/JSON: предпросмотр ничего не пишет в базу, подтверждение — пишет.
- Отчёт в CSV (`;`, BOM, CRLF) — открывается в Excel двойным щелчком.
- Сброс демо к исходному состоянию.

### Живая синхронизация
Данные синхронизируются между вкладками через `BroadcastChannel` и `storage`-событие.
Учитель подтверждает участие — у ученика во второй вкладке обновляются баллы, прогресс,
место и срабатывает анимация (120–520 мс, отключается при `prefers-reduced-motion`).

## Форматы данных

### Импорт
CSV (разделитель `,` или `;`, кавычки поддерживаются) или JSON-массив. Колонки:

| Колонка | Обязательна | Синонимы |
| --- | --- | --- |
| `student` | да | `ученик`, `фио`, `name` |
| `competition` | да | `конкурс`, `competition_id` |
| `status` | нет | `статус` (`pending`, `approved`, `rejected`) |
| `score` | нет | `баллы`, `балл` |
| `date` | нет | `дата` |

Строка отклоняется с понятной причиной: пустая, не хватает полей, ученик или конкурс не найден,
некорректный статус, баллы вне диапазона `0…maxScore`, дубликат заявки.

### Отчёт
`Ученик;Класс;Конкурс;Статус;Баллы;Дата регистрации` — UTF-8 с BOM, `;`, CRLF.

## Архитектура

```
src/
  data/          типы, seed, репозиторий на localStorage, импорт/экспорт, SVG-дипломы
  lib/           рейтинг, хук анимации изменения числа
  state/         сессия (SessionProvider) и живой снимок данных (useData)
  pages/         Login, Poster, Competition, Cabinet, Rating, Admin
  components/    Header, ImportPanel/ReportPanel
  styles/        tokens, layout, components, poster, admin, cabinet
```

- Слой данных спрятан за интерфейсом `Repository` — замена на REST/бэкенд не затронет страницы.
- Сессия хранит только id пользователя; всё остальное читается из репозитория.
- Сид пересоздаётся, когда меняется `SEED_VERSION`.
- Превью афиши — SVG в `public/poster-*.svg`, путь лежит в поле `Competition.image`; без картинки карточка заливается цветом направления.
- Импорт в режиме предпросмотра идёт через Proxy-репозиторий: `createParticipation` не пишет.

## Технологии

Vite 8, React 19, TypeScript 6, React Router 7, CSS без UI-библиотек, oxlint.
Шрифты — системные: Georgia (заголовки) и Manrope с фолбэком на Segoe UI (текст).

## Дизайн

«Школьный стенд достижений»: чернильный хвойный `#1E4D45`, тёплый янтарь, бумажный фон `#F4F2ED`.
Восьмипиксельная сетка, радиусы 8/12/999, тени только для иерархии, контраст текста не ниже 4.5:1.
Анимации — только для обратной связи (появление, изменение числа), 120–520 мс, с уважением к `prefers-reduced-motion`.

## Ограничения прототипа

- Нет сервера и авторизации: данные видны тому, кто открыл браузер; сессия — на вкладку.
- Дипломы — SVG, не PDF (осознанно: без внешних зависимостей).
- Импорт не поддерживает Excel-файлы напрямую — только CSV/JSON.
- Сброс демо очищает данные всех вкладок этого браузера.
